A recipient sees the ordinary viewer with writing switched off — one flag, checked by every mutator, moved in lockstep with the API scope so they cannot drift. Whether the share covers the sub-board tree is a per-recipient toggle, honoured in exactly one place so every view inherits the same answer.

A board you cannot see is a uniform **404, never 403**.
