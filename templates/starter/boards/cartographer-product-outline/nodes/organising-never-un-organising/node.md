created: '2026-07-31'

description: >-
  Agents may create folders, recolour them and file boards. No tool deletes a
  folder.
---

The line moved when a run could produce ten boards and leave every one loose for a person to file by hand. Deleting a folder stays human: nothing is archived and nothing is recoverable, because the folder *is* the arrangement — see [[Folders and favourites]]. Folders are addressed by name, so filing needs no id-tracking.
