Seven read, nineteen write. Every tool shapes arguments, calls the same service function the app itself calls, and returns JSON — so the two doors cannot drift apart. The original design named twelve tools; the extras each closed a way the twelve were *wrong*: no way to unmake a mislinked edge, move a node, colour a frame, or address an annotation.
